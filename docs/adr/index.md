# Decisões de arquitetura

Cada decisão importante fica registrada num ADR (*Architecture Decision Record*): o contexto, a decisão, as alternativas consideradas e as consequências. Um ADR aceito não é editado depois; se a decisão mudar, um ADR novo substitui o antigo.
